# Архитектура

## Слои

- `core/` — чистая логика (буфер, курсор, undo). Не зависит ни от чего, кроме std.
- `platform/` — платформенно-зависимый слой (терминал, файлы, время). Не зависит ни от чего, кроме ОС.
- `input/` — обработка ввода (Key, Parser, Keymap). Зависит от `command/` по именам.
- `command/` — реестр команд. Зависит от `core/`, `app/`.
- `app/` — состояние приложения (EditorState, Context). Связывает слои.
- `render/` — redisplay engine. Зависит от `core/`, `platform/`.
- `ui/` — статус-бар, minibuffer. Зависит от `render/`, `core/`.
- `script/` — встраиваемый скриптовый движок. Зависит от `command/`, `app/`.

## Запреты

1. `core/` не импортирует другие слои.
2. `platform/` не импортирует другие слои, кроме std.
3. `input/` не импортирует `platform/`.
4. `command/` не импортирует `input/`.
